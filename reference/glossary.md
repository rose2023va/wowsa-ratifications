# Glossary

Terminology in this domain is precise and easy to get wrong. Several terms are used differently
in different parts of the system, which is itself worth knowing.

| Term | Meaning |
|---|---|
| **SWIM ID** | The permanent identifier for a swim, format `SWIM-XXXX`. Minted by the Pre-Swim Planning form at submission, by a hidden auto-increment field feeding a calculation field. It appears in every email subject, every form, every page URL and every folder name. |
| **RAT #** | Not a separate identifier. The ratification confirmation email labels the swimmer's identifier "RAT #" and fills it with their SWIM ID. Swimmers quote it this way. |
| **Auto ID** | The underlying sequential number behind the SWIM ID, hidden on the form. Currently at index 1060. |
| **Ratified** | The committee's conclusion that a swim meets WOWSA ratification standards. |
| **Not Ratified** | The committee's conclusion that it does not. Used internally and in the workflow. **Never write "rejected".** |
| **Verified attempt** | The public and social-facing term for a swim that was not ratified. This is the wording used on the Canva assets. |
| **Attempted** | Also used internally for the same outcome. |
| **Route approval** | Confirmation that a planned route is sound. **Not ratification.** Should be stated explicitly whenever route approval is the news being delivered. |
| **Ratified distance** | The shortest straight-line tangent from start coordinates to finish coordinates. This is the record-relevant figure. |
| **GPS track distance** | The distance actually swum. Supporting evidence, not the record figure. |
| **Unassisted** | A swim under standard marathon swimming equipment rules. Record eligible. |
| **Assisted** | A swim using equipment beyond a swimsuit, one cap, goggles and earplugs. Receives certification, not ratification. Not record eligible. |
| **Independent observer** | The person who witnesses and documents the swim. Signs a three part agreement including a conflict of interest disclosure. |
| **Folder A** | The Google Drive folder created manually per swim, given to the swimmer and observer as an upload space. |
| **Folder B** | The Google Drive folder created automatically by Jotform, collecting files submitted through the forms. The working folder for building the ratification page. |
